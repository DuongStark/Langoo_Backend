# M10.4 — Triển khai thử Muse qua browser bridge

Ngày: 2026-10-07. Chủ dự án yêu cầu test/triển khai Muse-Chat-MCP và xác nhận
quota 1 tỷ token thuộc tài khoản web muse.ai. Quota do chủ dự án cung cấp;
chưa xác minh trên account, không coi là throughput/RPM bảo đảm.

Chốt phạm vi sử dụng sau lượt text đầu: **Muse cho job DB/nền; giữ Qwen cho chat**.
Không chuyển provider chat/quiz production và không đổi luồng DB4 đang chạy.

## Phạm vi và thứ tự

1. Pin upstream `6c00e8cf1bf2fb6718740e0c20d3578fb4c47286`, cài dependency
   không chạy install scripts; lưu lockfile phục vụ tái triển khai.
2. Dựng sidecar riêng trên VPS: Chrome dưới user langoo, profile riêng mode 0700,
   service/API loopback, không sửa runtime/app/env DB3/DB4 đang chạy.
3. Chuẩn bị browser đăng nhập qua màn hình riêng chỉ truy cập SSH tunnel;
   chủ dự án tự nhập thông tin tài khoản/2FA, agent không nhận mật khẩu/cookie.
4. Sau đăng nhập: smoke text VI/JA, JSON chọn sense, ảnh base64, SSE; đo thời gian
   hoàn tất và delta nội dung đầu tiên. Kiểm new thread không lẫn fixture cũ.
5. Nếu nối Langoo nhiều user: bổ sung isolation theo session hoặc gửi đủ context
   trong fresh thread; chặn API chưa auth, URL/path/files ngoài contract,
   timeout/approval/empty output; usage chỉ estimated. Không dùng shim nguyên bản
   cho chat nhiều user trước các gate này. Một queue, giới hạn backlog.

## Gate và trạng thái

- Test không chứa dữ liệu người học; ưu tiên fixture nhỏ, không chạy batch 100/5k
  trước smoke. Quota hiện tại không thay thế gate chất lượng hoặc session isolation.
- Chưa đổi provider production khi thiếu đăng nhập/test. Sidecar deploy khác
  trạng thái Langoo đã dùng Muse. FE không cần cài lại cho sidecar.
- Mọi script/config thay đổi lưu repo dưới `scripts/ops/`, report M10.4 và
  PROGRESS. Kiểm phù hợp + diff/status; không commit/push nếu chưa được yêu cầu.
- Rollback: stop sidecar và màn hình login; production giữ provider hiện có.
  Profile chứa credentials không lưu repo/artifact công khai.

Trạng thái ban đầu: đang triển khai thử; chưa live call/benchmark.
