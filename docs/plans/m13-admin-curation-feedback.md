## 1. Phạm vi v1 (đề xuất)

1. **Vai admin**: cột `app.users.role` (`user|admin`), `AdminGuard` (JWT + đọc DB: role=admin,
   status=active) — đổi quyền có hiệu lực ngay, không phụ thuộc claim cũ trong token.
2. **Thống kê vận hành (chỉ đọc)**:
   - `GET /v1/admin/stats` — snapshot: user theo status/tổng, đăng ký mới 7/30 ngày,
     tỉ lệ quay lại (`last_login_at` trong 7/30 ngày); học tập: lượt ôn 7/30 ngày, XP tổng,
     phân bố streak, số collection/item, quiz đã làm, backlog SRS đến hạn; nội dung:
     `gloss_report` theo status/issue/target_kind, concept `draft→curated`, tỉ lệ gloss máy vs
     đã duyệt, độ phủ `serve.sense_pair`; AI: request/token/chi phí 30 ngày theo feature, số user
     chạm quota ngày.
   - `GET /v1/admin/stats/timeseries?metric=signups|reviews|xp|ai_requests&days=30` — chuỗi theo ngày UTC.
3. **Feedback người dùng**:
   - `POST /v1/feedback` (đăng nhập): `{category: bug|feature|content|other, content 10..4000}`
     + multipart tối đa **3 ảnh ≤5MB** (jpeg/png/webp, kiểm magic bytes). `GET /v1/me/feedback`.
   - Admin: `GET /v1/admin/feedback?status=&category=&limit&cursor`, `GET /v1/admin/feedback/:id`
     (kèm URL ảnh xác thực), `PATCH /v1/admin/feedback/:id {status, admin_note}`.
   - Ảnh qua `StorageService` trừu tượng: `local` (dev/VPS, `STORAGE_DIR`, gitignore) / `s3` (khi có key
     — backlog; interface sẵn để đổi không đổi API). Admin xem ảnh qua route stream có guard,
     không public URL.
4. **Xử lý `gloss_report` (app schema)**: `GET /v1/admin/gloss-reports?status=&issue=&target_kind=`,
   `PATCH /v1/admin/gloss-reports/:id {status: triaged|fixed|rejected}` (set `resolved_at`).
5. **Khoá/mở user**: `PATCH /v1/admin/users/:id {status: active|locked}` (không xoá) — audit.
6. **Audit log**: bảng `app.admin_audit_log` (id, admin_user_id, action, target_kind, target_id,
   payload jsonb, created_at) — mọi mutation admin ghi 1 dòng trong cùng transaction.

## 3. Migration 030 (đề xuất)

```sql
ALTER TABLE app.users ADD COLUMN role text NOT NULL DEFAULT 'user'
  CHECK (role IN ('user','admin'));
CREATE INDEX users_admin ON app.users (id) WHERE role = 'admin';

CREATE TABLE app.feedback (
  id uuid PRIMARY KEY,
  user_id bigint NOT NULL REFERENCES app.users(id) ON DELETE CASCADE,
  category text NOT NULL CHECK (category IN ('bug','feature','content','other')),
  content text NOT NULL CHECK (btrim(content) <> ''),
  status text NOT NULL DEFAULT 'new' CHECK (status IN ('new','in_progress','resolved')),
  admin_note text,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX feedback_queue ON app.feedback (status, created_at);

CREATE TABLE app.feedback_attachment (
  id uuid PRIMARY KEY,
  feedback_id uuid NOT NULL REFERENCES app.feedback(id) ON DELETE CASCADE,
  storage_key text NOT NULL CHECK (btrim(storage_key) <> ''),
  mime text NOT NULL CHECK (mime IN ('image/jpeg','image/png','image/webp')),
  size_bytes integer NOT NULL CHECK (size_bytes > 0),
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX feedback_attachment_by_feedback ON app.feedback_attachment (feedback_id);

CREATE TABLE app.admin_audit_log (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  admin_user_id bigint NOT NULL REFERENCES app.users(id) ON DELETE CASCADE,
  action text NOT NULL,
  target_kind text,
  target_id text,
  payload jsonb NOT NULL DEFAULT '{}'::jsonb CHECK (jsonb_typeof(payload) = 'object'),
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX admin_audit_recent ON app.admin_audit_log (created_at DESC);
```

Bootstrap admin: câu SQL một dòng (`UPDATE app.users SET role='admin' WHERE lower(email)=...`)
— ghi trong README, không có endpoint tự phong admin.

## 4. API (chi tiết)

| Endpoint | Ghi chú |
| --- | --- |
| `GET /v1/admin/stats` | aggregate-only, không lộ dữ liệu cá nhân |
| `GET /v1/admin/stats/timeseries?metric&days` | metric whitelist, days 1..180 |
| `POST /v1/feedback` | multipart (`content`, `category`, `files[]`) + rate limit 10/giờ/user |
| `GET /v1/me/feedback?limit&cursor` | user xem lại + trạng thái + admin_note |
| `GET /v1/admin/feedback?status&category&limit&cursor` | hàng chờ |
| `GET /v1/admin/feedback/:id` | kèm metadata ảnh (id mime size) |
| `GET /v1/admin/feedback/:id/attachments/:attachmentId` | stream ảnh, guard admin |
| `PATCH /v1/admin/feedback/:id` | `{status, admin_note?}` → audit |
| `GET /v1/admin/gloss-reports` + `PATCH /v1/admin/gloss-reports/:id` | xử lý báo lỗi gloss |
| `PATCH /v1/admin/users/:id` | khoá/mở (active/locked) → audit |
| `GET /v1/admin/audit-log?limit&cursor` | xem lịch sử thao tác admin |

Lỗi mới: `403 ADMIN_REQUIRED` · `404 FEEDBACK_NOT_FOUND` · `400 ATTACHMENT_INVALID` (magic bytes/mime/size) ·
`409 USER_STATUS_INVALID` (tự khoá chính mình / trạng thái không hỗ trợ) · `413 ATTACHMENT_TOO_LARGE`.

## 7. Sửa sau review 2026-10-05

- Guard feedback xác thực JWT trước khi tính quota theo user; global IP limit vẫn áp dụng.
- Cursor M13 giữ timestamp PostgreSQL đủ 6 chữ số và so sánh tuple timestamp/id trong SQL.
- Row lock bảo vệ eligibility khi đổi trạng thái user; audit feedback giữ status/ghi chú trước và sau dưới cùng row lock.
- Quota hôm nay theo timezone của từng user; backlog SRS bỏ thẻ archive/paused/buried và lọc profile/ngôn ngữ phù hợp.
- Cleanup bao gồm key của lần upload đang ghi lỗi; interceptor chuẩn hóa lỗi multipart theo hợp đồng API.
- Không migration, dependency hoặc env mới. Kiểm chứng và giới hạn tại recheck.
