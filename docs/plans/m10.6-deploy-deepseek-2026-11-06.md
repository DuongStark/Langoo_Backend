# M10.6 — DeepSeek Deploy cho chat và quiz

Ngày 06/11/2026. Chủ dự án cấp Secret Key qua phiên và yêu cầu thay Groq bằng
DeepSeek qua portal.deploy.com để giảm chi phí. Không lưu key/Access Key ID trong repo.

## Phạm vi

- Xác minh auth/endpoint/model từ docs Deploy, không đoán secret là client ID hoặc
  gửi sang provider khác. Official endpoint https://api-cdn.deploy.com/api/v1,
  Bearer Secret Key; Access Key ID dùng quản lý, không phải bearer.
- Thử model deepseek-ai/deepseek-v4.1-flash với fixture giả: text, stream parser thật,
  JSON quiz, ảnh giả/multi-turn để không âm thầm mất tính năng nhận ảnh.
- Dự kiến chỉ đổi ENV đang có cho chat + quiz, không thay API/DB/schema. Giữ token
  cap/quota/consent/rate-limit. Chỉ đổi code nếu smoke chứng minh tương thích chưa đủ.
- Backup .env server có phân quyền, update atomic đúng các AI_* đã chọn; validation
  config trước reload. Rollback về backup nếu provider/health fail; không đổi các
  secret/env không liên quan. Provider change/reload là việc cần thiết để thực hiện
  yêu cầu thay Groq; chưa tự push code/docs khi chưa được yêu cầu riêng.
- Không gửi chat/user/DB/PDF thật cho smoke, không mua/nạp credit hoặc đổi billing.
  Số request nhỏ, output cap hữu hạn. Không tự đổi model do client nếu model ngoài
  cấu hình cần quyết định sau khi kiểm code hiện tại.

## Kiểm chứng và bàn giao

1. HTTPS auth/text/JSON, stream actual OpenAiChatProvider và ảnh giả; ghi status,
   usage/latency thực đo, không khẳng định chi phí thực nếu không có billing.
2. Nếu ENV-only, chạy validateEnv/current provider factory với cấu hình mới; không
   chạy lại toàn bộ DB suite khi không thay code. Kiểm model string được ghi metadata.
3. Sau update/reload: health + manifest, process ENV đã che secret; smoke provider
   trên server qua code transport thật, không mint token/ghi consent/user thật.
4. Cập nhật ENV mẫu (không secret), ops/FE handoff về tên vendor/mô hình và giới hạn
   tính năng/notice, PROGRESS, review; diff/link/status. Nêu đúng code/Git/deploy state.

## Bổ sung yêu cầu: tắt thinking và đo10lượt học thực tế

Người dùng yêu cầu `reasoning_effort=none` và benchmark10lượt. Đã đo bằng API trực
tiếp + prompt thật Langoo, history tăng dần, reasoning_tokens0/10 lượt. Schema BE
hiện không nhận none; quiz chưa có effort config nên cần bổ sung code nhỏ: enum
chat/quiz có none, AI_QUIZ_REASONING_EFFORT truyền tới gen/validator/retry. Giữ
undefined cho env cũ để tương thích ngược, không tự đặt none cho provider khác.
TDD: env acceptsnone/rejectinvalid và provider factory forwardnone mọi call.
