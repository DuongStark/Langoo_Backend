# M10.3 — Chat nhận ảnh tạm thời

2026-10-07. Chủ dự án đã yêu cầu code BE và apply VPS.

- Thêm `images?: string[]` data URLs PNG/JPEG/WebP vào hai endpoint
  `POST /v1/chat/sessions/:id/messages` và `/messages/stream`.
- Tối đa 3 ảnh, mỗi ảnh tối đa 2 MiB decoded; JSON route tối đa 9 MiB. Kiểm
  canonical base64 và chữ ký format. Không fetch URL ngoài, không ghi file/DB ảnh.
- Provider ghép text + image_url chỉ trong lượt hiện tại; lịch sử chỉ text.
- Chặn stub khi có ảnh, trước reserve quota; giữ auth/lease/quota hiện tại.
- Không log body ảnh hoặc chi tiết upstream có thể echo ảnh. Không migration/FE.
- Test validation/forwarding/persistence/history/error/stream, build/lint và
  release cô lập từ commit VPS; backup dist, reload, smoke thật và kiểm DB text.
