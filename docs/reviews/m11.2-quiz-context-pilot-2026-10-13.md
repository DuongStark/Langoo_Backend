# M11.2 — Quiz ngữ cảnh: pilot model thật + sửa timeout (2026-10-13)

Chủ dự án yêu cầu chuyển quiz AI sang "model thật". Kiểm tra + pilot trên VPS.

## Hiện trạng trước khi sửa

- VPS đã deploy M11.1 (dist build 2026-10-12) với `ContextQuizProvider` +
  transport thật: `AI_PROVIDER=openai`, `AI_API_KEY` (gateway
  `https://spacebunnymodel.com/api/v1`), `AI_QUIZ_MODEL` =
  `AI_QUIZ_VALIDATOR_MODEL` = `space-bunny-alpha` (cùng model chat M10).
- Factory thật đã kích hoạt: provider name = `hybrid-context` (không phải stub).
- **Thiếu cấu hình:** `AI_QUIZ_TIMEOUT_MS` chưa đặt → mặc định **60s** — quá ngắn
  cho sinh ngữ cảnh (mỗi câu cần 1 call sinh + 1 call kiểm).

## Pilot thật (không mock)

Chạy đúng code production (`dist/ai/providers/*.js`) + env thật trên VPS, 8 từ
Kanji (学校/天気/電車/友達/水/本/花/犬), `question_styles=[kanji_reading]`,
`context_mode=source_or_generated`:

- **8/8 câu** nhận ngữ cảnh AI sinh; validator (cùng model) chấp nhận đủ
  `natural/correctSense/correctTarget/noAnswerLeak` + 1 đáp án đúng.
- Câu tự nhiên, ví dụ: 私の子供は毎日学校へ歩いて行きます。 · 庭に赤い花が咲いている。
  · 私は毎日電車で会社に行きます。 · うちの犬は毎日公園を散歩するのが好きです。
- Offsets highlight khớp target; options nhiễu lấy từ từ khác trong scope.
- **Thời gian:** 16 call = 246s (đa số 3-15s/call, 2 call ~75s). Ước lượng
  ~30s/câu ngữ cảnh → 8 câu ~4 phút; timeout mặc định 60s sẽ hỏng từ ~2-3 câu.

## Thay đổi đã áp (VPS)

- `/opt/langoo/app/.env`: thêm `AI_QUIZ_TIMEOUT_MS=300000` (mức tối đa schema cho phép).
- Backup env: `/opt/langoo/storage/config-backups/m11.2-quiz-timeout-20261013-0852.env` (0600).
- `pm2 reload langoo-api`; sau reload `/v1/health` = 200 (app đọc `.env` lúc boot qua
  `ConfigModule.forRoot`, nên reload ăn cấu hình mới).
- Caddy `reverse_proxy` không đặt read-timeout → request dài tới 5 phút qua được.
- Rollback: xoá dòng `AI_QUIZ_TIMEOUT_MS` (về mặc định 60s) hoặc restore backup + reload.

## Còn lại / ghi chú

- FE chưa tích hợp chọn style/context (handoff: `docs/handoff/quiz-kanji.md`).
- Sinh ngữ cảnh tuần tự 2 call/câu; có thể song song hóa nhiều slot (chưa làm) để rút
  thời gian; evidence được cache/reuse cho các quiz sau nên chỉ chậm lần đầu mỗi sense.
- Validator dùng cùng model với generator — không phải 2 reviewer độc lập (giới hạn
  đã biết từ M10.2); pilot này đủ để xác nhận wiring thật + chất lượng cơ bản.
- Không đổi model: `space-bunny-alpha` đạt pilot này và đang dùng chung cho chat.
