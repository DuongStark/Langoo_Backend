1. **64 unresolved = `TimeoutPendingRemote`** (browser-bridge timeout): dispute, overcome, opinion, furniture, battle, wonder, default, recall, radiation… (~1,3%). Runner hỗ trợ resume → **nên chạy lại**.
2. **116 từ 0 selection — TẤT CẢ đều nằm trong `needs_review`** (không im lặng): proper noun (york, washington, canada, facebook…), viết tắt (mr, uk, vs, etc, cia…), tháng/ngôn ngữ (june, french, spanish…), biến thể (states, issues, shares…). → lọc ở cohort tương lai.

4. **Tổng không dùng được ngay: 64 + 116 = 180/5.000 (3,6%)**; 4.820 từ còn lại có ranking dùng được.

## 4. Khuyến nghị trước khi M4.5 áp DB

1. **Resume 64 timeout** (service bulk) — lấy thêm ~1,3% từ thông dụng.
2. Khi apply: chỉ áp ranking cho từ có `selections`; từ 0 selection để fallback thứ tự mặc định (hoặc bỏ khỏi cohort).
3. `needs_review` giữ làm metadata như policy; không cần judge.
4. Cohort lần sau: lọc proper-noun/viết tắt/dạng biến thể (hoặc đánh dấu riêng).
5. `results.jsonl` 3,1MB/4.936 từ — đủ nhẹ để import; chưa apply DB, chưa commit (thuộc agent M10.5).
