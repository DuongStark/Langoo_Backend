# M10.1 — Khôi phục chat sau lỗi provider 502

Ngày: 2026-10-27 (Asia/Bangkok). VPS release code `243585a`.

- Người dùng báo HTTP 503 sau deploy M10.1 ngày 26/10. Log production cho thấy
  Space Bunny trả HTTP 502 hai lần, backend trả `AI_PROVIDER_UNAVAILABLE` 503.
  Gọi trực tiếp upstream bằng nội dung giả lập: cả streaming lẫn non-streaming
  đều nhận 502 từ Cloudflare. Địa chỉ `www` từng trả 200 một lần nhưng lần thử sau
  lại 502; chưa coi là khôi phục ổn định. File `.env` Space Bunny đã có từ 13/10.
- Commit `13d59cb` thay parser SSE, hủy/retry/persist, và chờ delta đầu mới gửi
  event `start`. Lỗi upstream trước delta hiện trả HTTP 503 JSON; trước đó headers
  SSE đã gửi sớm. Điều này thay đổi cách lỗi xuất hiện; 502 được tái hiện khi gọi
  trực tiếp provider, trước parser SSE của Langoo.
- Chủ dự án chọn chuyển tạm chat sang Groq. VPS đổi `AI_BASE_URL`, `AI_API_KEY`,
  `AI_CHAT_MODEL`; model tạm cuối cùng `qwen/qwen3.8-27b` để hỗ trợ chữ và ảnh.
  Các biến quiz riêng được giữ nguyên. Không sửa code hoặc schema DB. Nội dung
  chat mới được gửi tới Groq trong thời gian cấu hình này có hiệu lực.
- Sao lưu cấu hình trước khi chuyển tại thư mục riêng `/opt/langoo/storage/ops/`
  (file `m10.1-provider-before-groq-20261027-*.env`, mode 600); giữ thêm backup
  trước khi đổi model Groq. Không đưa key hoặc nội dung các file vào repo.
- Kiểm tra sau restart: PM2 `langoo-api` online, public health HTTP 200, DB OK UTC;
  adapter production dùng cấu hình mới gọi stream chữ và ảnh PNG mẫu thành công,
  lần lượt 9 và 34 delta. Chủ dự án xác nhận chat chữ trong ứng dụng trả lời bình
  thường; log request stream HTTP 200. Chưa có xác nhận gửi ảnh từ UI thật.
- Hạn chế: provider/model khác có thể đổi chất lượng hoặc giới hạn. Space Bunny
  cần được kiểm lại trước khi chuyển về; không lấy HTTP 200 một lần làm bằng
  chứng ổn định. Không kiểm thử toàn bộ chức năng AI/quiz trong lượt vận hành.
- Git: thay đổi thực tế ở cấu hình riêng trên VPS, không commit secret. Report,
  PROGRESS và runbook chỉ là tài liệu local chưa commit/push.
