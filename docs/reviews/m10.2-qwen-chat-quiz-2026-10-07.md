# M10.2 — Cấu hình Qwen cho chat và quiz

Ngày: 2026-10-07. Chủ dự án yêu cầu đổi model chat AI và quiz AI sang Qwen.

## Thay đổi và phạm vi

- Dùng `qwen/qwen3.8-27b` trên gateway Groq hiện có; catalog `/models` xác thực
  bằng key trên VPS trả model này. Không đổi key/provider/base URL VPS.
  [Groq models](https://console.groq.com/docs/models) ghi đây là model preview.
- Local `.env` và VPS `.env`: `AI_CHAT_MODEL`, `AI_QUIZ_MODEL`,
  `AI_QUIZ_VALIDATOR_MODEL` cùng ID trên. Clear `AI_CHAT_REASONING_EFFORT=low`
  của GPT-OSS để không gửi tham số suy luận chưa kiểm cho model mới.
- `.env.example`, `docs/api/chat.md`, `docs/api/quizzes.md` đồng bộ cấu hình.
  Demo provider vẫn là stub trong file mẫu; key thật không lưu repo.
- Không cần hardcode model vào provider: chat và context quiz local đã đọc env.
  Quiz dữ liệu vẫn không gọi AI. Hai lượt sinh/kiểm cùng model không phải hai
  reviewer độc lập; chưa nghiệm thu chất lượng ngữ cảnh tiếng Nhật.

## VPS và giới hạn runtime

- Đã backup env riêng với mode 0600 dưới
  `/opt/langoo/storage/config-backups/m10.2-qwen-<timestamp>.env`, giữ owner/mode
  env và replace file, reload `langoo-api` qua PM2. Không build/pull code mới.
- **Chat:** cấu hình Qwen đã kích hoạt sau reload; completion thường HTTP200,
  streaming bằng compiled `OpenAiChatProvider` trả nội dung, đúng model, 4 delta.
  Không smoke authenticated user chat route trong lượt này.
- **Quiz:** cấu hình Qwen đã lưu VPS, nhưng cả source và compiled quiz factory
  trên VPS vẫn dùng `StubQuizProvider`. Bản AI ngữ cảnh `ContextQuizProvider`
  M11.1 chỉ có trong working tree local. Chưa phát hành M11.1, không báo quiz
  production đã gọi Qwen. Cần release M11.1 đã kiểm riêng để sử dụng các biến này.
- Health lần gọi ngay sau reload chưa kịp bind port (curl exit7); kiểm lại sau
  khởi động HTTP200, `status=ok`, `db=ok`, DB timezone UTC. Không có lỗi kéo dài.

  M10.3 là ước lượng Qwen, phải kiểm/đổi nếu provider mới thiếu usage.
- Cloudflare Workers AI: [pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/)

  ngang Gemini về chất lượng chỉ dựa vào model size hoặc tên provider.
- OpenRouter: [pricing](https://openrouter.ai/pricing/) free 50 requests/day;
  [support chính thức](https://openrouter.zendesk.com/hc/en-us/articles/39501163636379-OpenRouter-Rate-Limits-What-You-Need-to-Know)

  model hỗ trợ ảnh, nhưng không chọn làm chính cho yêu cầu free nhiều lượt.

## 2026-10-07 — M10.2 — Khảo sát Muse-Chat-MCP

- Phạm vi: đọc README và source của
  [Muse-Chat-MCP](https://github.com/duclm1x1/Muse-Chat-MCP/tree/6c00e8cf1bf2fb6718740e0c20d3578fb4c47286),
  commit `6c00e8cf1bf2fb6718740e0c20d3578fb4c47286`, clone riêng trong `/tmp`.
  Không cài dependencies/chạy code/login, gọi model hoặc đổi VPS.
- Đây là browser bridge không chính thức: Playwright điều khiển Chrome đăng nhập
  Muse; cung cấp MCP stdio, CLI và HTTP OpenAI-compatible localhost `8787/v1`.
  Tài khoản/quota do người dùng cung cấp; repo không chứng minh hạn mức miễn phí,
  throughput hay latency. License repo MIT không xác định quyền/quota dịch vụ Muse.
- `muse-openai-shim.mjs`: `model` chỉ gắn nhãn response/log, không được chuyển
  vào driver để chọn model; `max_tokens`/`temperature` không được áp dụng.
  Prompt ghép system thành văn bản + user/tool mới nhất; lịch sử còn lại dựa vào
  thread Muse. Có chọn chat/new thread nhưng chưa có mapping/ownership Langoo
  session; mặc định dùng thread hiện tại, có nguy cơ lẫn ngữ cảnh nhiều user.
- `muse-driver.mjs`: một page và queue tuần tự; SSE lấy text DOM ổn định,
  không phải native token streaming. Selector/login là phụ thuộc vận hành.
  Data URI ảnh được chuyển Buffer rồi `setInputFiles`, không có thao tác tự ghi
  file ảnh đầu vào trong nhánh này; ảnh vẫn upload sang Muse, không bảo đảm
  retention của Muse/browser. Download media là chức năng riêng có ghi file.
- Shim không kiểm Bearer key; mặc định loopback. Có nhận URL/path attachment
  và đọc chat: nếu thử phải giữ nội bộ, không expose trực tiếp ra Internet.
  Usage thường là chars/4, SSE completion_tokens=0 và không tính ảnh; không dùng
  làm usage thực cho quota Langoo. Driver báo timedOut/needsApproval nhưng shim
  chưa chuyển các cờ này thành lỗi, có thể trả reply chưa đủ với finish stop.
- README/comment có chỗ lỗi thời về full transcript/single conversation; căn cứ
  hành vi source ở commit trên. Không coi ID công bố là catalog model upstream.
- Đề xuất: thử local/offline pilot M4.5 qua queue + cache/checkpoint/JSON validation
  nếu chủ dự án chọn; xác minh fresh thread, chất lượng, quota và timeout trước.
  Chưa chọn làm provider chat/quiz nhiều user; cần isolation, auth, usage và gate
  text/ảnh/SSE thực tế. Không liên quan adapter OpenCode Zen đã dùng DB3-B.
- Kiểm tra: đối chiếu source local và links primary; không runtime tests/benchmark.
  File thay đổi: report này + PROGRESS. Docs lưu local, chưa commit/push;
  production tiếp tục cấu hình Qwen/Groq hiện có.
