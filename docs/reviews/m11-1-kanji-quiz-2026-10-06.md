## Cách kiểm tra

Collection cần nguồn forms/restrictions đủ và target + ba distractor hợp lệ:

```bash
curl -s -X POST http://localhost:3000/v1/quizzes \
  -H 'Authorization: Bearer <access_token>' \
  -H 'Content-Type: application/json' \
  -d '{"collection_id":"<uuid>","quiz_type":"multiple_choice","question_styles":["kanji_reading","kanji_orthography"],"context_mode":"none","difficulty":"medium","question_count":10}'
```

Kỳ vọng 201 ready; GET có hai question_style và 4 options/câu. Gửi option_index qua
endpoint answers hiện hữu. Đổi context_mode sang source_or_generated để dùng ngữ cảnh;
cấu hình AI_QUIZ_MODEL / AI_QUIZ_VALIDATOR_MODEL cùng transport OpenAI-compatible khi cần gọi thật.
