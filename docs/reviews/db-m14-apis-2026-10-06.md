## 1. `GET /v1/admin/users` (trước đây chỉ có `PATCH /v1/admin/users/:id`)

- Guard `AdminGuard` (JWT + `role='admin'` + active); không token → 401.
- Query: `status` (`active|locked|deleted`), `role` (`user|admin`), `q` (contains email/tên hiển thị, escape `%_\`), `limit` 1..100 (default 20), `cursor`.
- Keyset `(created_at, id) DESC` dùng `time-cursor` chung; response `{ data, next_cursor }`.
- Chỉ metadata tài khoản (đúng chính sách M13): `id, email, display_name, role, status, created_at, last_login_at` — không nội dung học tập.
- Code: `src/admin/admin-users.service.ts` (thêm `list()`), `AdminUsersController.@Get()`, DTO `AdminUserQueryDto/AdminUserDto/AdminUserListResponseDto`.
- Test: 7/7 suite admin (2 test mới cho list: map + cursor, rỗng + next_cursor null).

## 2. `GET /v1/kanji/:literal/stroke.svg` (ảnh thứ tự nét KanjiVG)

- Nguồn: `core.kanji_media` (kind `stroke_svg`) → `core.media_asset.object_key` (vd `kanjivg/0732b.svg`) → đọc file qua `STORAGE_SERVICE` (local, `STORAGE_DIR=/opt/langoo/storage`).
- Route công khai, trả `image/svg+xml`, `Cache-Control: public, max-age=86400, immutable`, `ETag` = sha256 asset; thiếu metadata/file → 404 `KANJI_STROKE_NOT_FOUND`.
- Code: `KanjiRepository.getStrokeAsset()`, `DictionaryService.getKanjiStroke()`, route trong `KanjiController` (dùng `StreamableFile` như feedback attachments).
