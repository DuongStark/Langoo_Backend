## Code và contract

- [Migration](../../db/migrations/045_concept_images.sql): bổ sung media kind/metadata,
  bảng nối concept–asset với anchor sense và review provenance, primary unique, view có gate.
- [CLI và hướng dẫn](../../scripts/media/README.md): upload/dry-run/register/apply đúng migration.
  Runtime SDK tách riêng, không thêm app dependency hoặc map core vào Prisma.
- Manifest nguồn kiểm PNG/hash/path, source sense/definition và prompt đã lưu.
  Registrar kiểm public bytes lại trên VPS, hash definition nguồn và mapping hiện tại trong transaction;
  definition đổi thì rollback trước khi ghi. Không chọn concept bằng lemma, không tự duyệt pending cũ.
- DB lưu key/hash/prompt/definition/provenance; model revision không được Muse cung cấp nên để null.
  Không lưu credentials/blob/URL tạm. Chính sách provenance không khẳng định ảnh là CC0.
- Consumer đọc `serve.concept_image`; URL = public base cấu hình + `/` + object key.
  Chưa thay response API hoặc hiển thị ảnh trên FE.
