## 10. Sự cố search chậm 10/10 (zombie query) — đã sửa

- **Triệu chứng**: search chậm toàn hệ (~2-3,5s); tìm thấy **4 query search chạy 4,5 tiếng** (từ 15:00), mỗi cái ~18% CPU → load 5,9.
- **Nguyên nhân**: query 1 ký tự → bigram filter rỗng → 318k match (q=`a`) → `visible` NOT EXISTS self-join O(N²) không hồi kết; client abort nhưng server chạy tiếp (không statement_timeout) → tích tụ zombie.
- **Fix** (`dictionary-search.repository.ts`, cả bản VPS + branch):
  1. `settings` CTE: `set_config('statement_timeout','20000',true)` — mọi query search tự chết sau 20s dù client bỏ.
  2. Cap `hits` 5000 (thứ tự rẻ: exact → prefix → len → frequency) — chặn pipeline nổ.
  3. `canonical MATERIALIZED` thay NOT EXISTS self-join (bỏ O(N²)); JA/VI/EN logic giữ nguyên.
- **Kết quả**: query thường 0,1-0,9s (bank/cat/学生/tree kết quả không lệch); 1-ký-tự: JA 7-14s, EN ~12s (sàn seq-scan view 2-4M dòng — 1 ký tự không index nào cứu được); zombie test: abort → query tự chết ≤20s ✓.
- Backup: `dictionary-search.repository.ts.bak-20261010-193632`.
- **FE nên**: debounce ≥2 ký tự cho EN (1 ký tự vẫn chạy nhưng chậm); JA 1-kanji chấp nhận chậm, cải thiện sau nếu cần.
