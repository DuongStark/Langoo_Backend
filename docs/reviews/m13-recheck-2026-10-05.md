## Áp dụng và giới hạn

- Không migration, dependency hoặc env mới; sử dụng schema M13 hiện có từ
  migration 030. Cần build/restart API khi deploy theo runbook VPS.
- Storage trên VPS dùng thư mục cố định `/opt/langoo/storage` ngoài repo;
  S3 vẫn là backlog. Cleanup khi bắt được lỗi là best effort như trước.
- Cursor mới vẫn là opaque v1, thêm precision; timestamp millisecond cũ
  vẫn được chấp nhận. Sau deploy nên tải lại trang đầu để nhận cursor mới;
  phần microsecond đã mất trong cursor cũ không thể tự khôi phục.
- Thay đổi precision trong lượt này áp dụng cho các queue M13. Interface
  cursor Date dùng bởi chat/quiz được giữ tương thích; test liên quan pass.
- Rate limit vẫn lưu trong RAM theo thiết kế một instance. Chưa stress test
  VPS, triển khai shared storage hoặc thay đổi vòng đời access token.
- Bản sửa M13 chỉ ở local; không deploy/restart hoặc sửa .env VPS trong phiên này.
