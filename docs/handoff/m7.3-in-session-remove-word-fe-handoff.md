# M7.3 — FE handoff: Xoá từ khỏi bộ sưu tập trong phiên học Flashcard

Ngày: 2026-10-28. Milestone: `M7.3`.
Backend: Đã hoàn thiện endpoint `DELETE /v1/sessions/:id/items/:ordinal`, đã kiểm tra unit tests (`PASS`).

---

## 1. Bối cảnh & Mục đích

Khi người học đang học hoặc ôn tập Flashcard (cả chế độ `review` do đến hạn SRS lẫn `practice` ôn trước hạn):
- Nếu gặp một từ quá dễ, từ không cần thiết hoặc muốn loại bỏ hoàn toàn khỏi bộ từ cá nhân, người học có thể chọn **"Xoá khỏi bộ từ"** ngay trên giao diện thẻ flashcard.
- Thao tác này:
  1. Xoá vĩnh viễn từ (`collection_item`) khỏi bộ sưu tập của người dùng trong cơ sở dữ liệu.
  2. Cascade xoá toàn bộ các mặt thẻ liên quan (`collection_item_face`), trạng thái ôn tập SRS (`srs_state`), và tag của từ.
  3. Tự động giảm `item_count` của bộ sưu tập (`collection`).
  4. Loại bỏ câu hỏi/thẻ hiện tại (và bất kỳ mặt thẻ đối ứng nào của cùng từ đó, ví dụ thẻ nhận biết và thẻ gợi nhớ) ra khỏi phiên học hiện tại mà không làm lệch thứ tự hay gián đoạn tiến độ.
  5. Cập nhật lại chỉ số thống kê của phiên học (`item_count`, `correct_count`, `status`, `score`).

> [!NOTE]
> Endpoint này **chỉ áp dụng cho phiên học Flashcard / Practice / Review**. Không hỗ trợ trong phiên `quiz` (nếu gọi trong phiên quiz, API sẽ trả về lỗi `400 SESSION_ACTION_UNSUPPORTED`).

## 2. Chi tiết API Endpoint

### Method & URL
```http
DELETE /v1/sessions/:id/items/:ordinal
```

### Request Headers
```http
Authorization: Bearer <jwt_access_token>
Content-Type: application/json
```

### Path Parameters
| Tham số | Kiểu | Mô tả | Ví dụ |
| :--- | :--- | :--- | :--- |
| `id` | `string` (UUID) | ID của phiên học hiện tại (`session.id`) | `01a18014-bdee-72d8-9891-b3fefa8ec160` |
| `ordinal` | `number` (integer) | Số thứ tự câu hỏi/thẻ đang hiển thị (`item.ordinal`) | `1` |

### Request Body
Không có (Body rỗng).

## 3. Kiểu dữ liệu TypeScript & Response

### TypeScript Interfaces
```ts
export interface RemoveSessionWordResponse {
  /** ID của collection_item đã xoá vĩnh viễn */
  item_id: string;

  /** ID của bộ sưu tập chứa từ đã xoá */
  collection_id: string;

  /**
   * Danh sách ordinal các câu hỏi trong phiên này đã bị loại bỏ.
   * Thường là [ordinal] hiện tại. Nếu từ có cả 2 chiều (nhận diện + gợi nhớ)
   * cùng nằm trong phiên, API sẽ trả về cả 2 ordinal để FE loại bỏ hoàn toàn.
   */
  removed_ordinals: number[];

  /** Trạng thái phiên học sau khi loại bỏ thẻ */
  session: SessionResponse;
}

export interface SessionResponse {
  id: string;
  kind: string; // 'review' | 'practice'
  mode: string; // 'flashcard'
  collection_id: string | null;
  status: string; // 'in_progress' | 'completed' | 'abandoned'
  item_count: number; // Tổng số thẻ còn lại trong phiên
  answered_count: number; // Số thẻ đã trả lời
  correct_count: number; // Số thẻ trả lời đúng
  score: number | null; // Điểm số (0..100) nếu đã kết thúc
  xp_awarded: number;
  settings: Record<string, unknown>;
  started_at: string;
  finished_at: string | null;
}
```

## 4. Xử lý mã lỗi (Error Codes)

| HTTP Status | Mã lỗi (`code`) | Ý nghĩa & Hướng xử lý phía FE |
| :--- | :--- | :--- |
| `400 Bad Request` | `SESSION_ACTION_UNSUPPORTED` | Cố gắng gọi xoá từ trong phiên `quiz`. FE nên ẩn nút xoá khi đang ở màn quiz. |
| `404 Not Found` | `SESSION_NOT_FOUND` | Phiên không tồn tại hoặc không thuộc user. Điều hướng về trang chủ / danh sách bộ từ. |
| `404 Not Found` | `SESSION_ITEM_NOT_FOUND` | Thẻ theo ordinal không tìm thấy trong phiên (có thể do đã xoá trước đó). Bỏ qua thẻ này. |
| `404 Not Found` | `COLLECTION_ITEM_NOT_FOUND` | Từ không còn tồn tại trong bộ từ. |
| `409 Conflict` | `SESSION_CLOSED` | Phiên học đã kết thúc (`completed` hoặc `abandoned`). Chuyển về màn hình kết quả phiên. |
| `403 Forbidden` | `COLLECTION_FORBIDDEN` | Bộ từ không thuộc quyền sở hữu của user hiện tại. |

## 5. Hướng dẫn tích hợp UI/UX phía Frontend

### Bước 1: Đặt nút thao tác trên Thẻ Flashcard
- Thêm một nút icon (ví dụ icon thùng rác `Trash2` hoặc nút menu 3 chấm `MoreVertical` có tuỳ chọn **"Xoá khỏi bộ từ"**).
- Vị trí gợi ý: Ở góc trên bên phải của khung thẻ Flashcard (kế bên nút phát âm / bookmark nếu có).
- **Chỉ hiển thị** khi người dùng đang học Flashcard thuộc bộ sưu tập cá nhân (không hiển thị ở chế độ Quiz).

### Bước 2: Hiển thị Dialog / Modal xác nhận
Để tránh người dùng bấm nhầm khi đang lật thẻ nhanh, bắt buộc hiển thị hộp thoại xác nhận:
- **Tiêu đề:** Xoá từ khỏi bộ từ?
- **Nội dung:** Từ này sẽ bị xoá vĩnh viễn khỏi bộ từ của bạn và toàn bộ tiến độ ôn tập (SRS) của từ sẽ bị xoá. Bạn có chắc chắn muốn xoá không?
- **Hành động:** Nút "Huỷ" và nút "Xoá từ" (màu đỏ / danger).

### Bước 3: Cập nhật State khi gọi API thành công
Khi nhận response HTTP 200 từ `DELETE /v1/sessions/:id/items/:ordinal`:

```ts
// 1. Loại bỏ tất cả các thẻ có ordinal nằm trong removed_ordinals ra khỏi mảng thẻ local
setCards((prevCards) =>
  prevCards.filter((card) => !response.removed_ordinals.includes(card.ordinal))
);

// 2. Cập nhật tiến độ phiên học (Progress Bar)
setSessionStats({
  itemCount: response.session.item_count,
  answeredCount: response.session.answered_count,
});

// 3. Kiểm tra xem phiên học đã kết thúc chưa
if (response.session.status === 'completed') {
  // Toàn bộ thẻ trong phiên đã được trả lời hoặc đã bị xoá hết
  // Điều hướng người học sang màn hình Kết quả phiên học (Session Result)
  navigation.navigate('SessionResult', { session: response.session });
  toast.success('Đã xoá từ. Phiên học đã hoàn thành!');
} else {
  // Phiên học vẫn còn thẻ: thẻ kế tiếp tự động hiển thị mượt mà
  // (Do phần tử hiện tại đã bị xoá khỏi mảng cards, phần tử kế tiếp trượt lên vị trí index hiện tại)
  toast.success('Đã xoá từ khỏi bộ từ thành công');
}
```

> [!TIP]
> Không cần tải lại (reload) toàn bộ phiên học từ đầu bằng `GET /v1/sessions/:id`. Hãy dùng trực tiếp `response.removed_ordinals` và `response.session` để cập nhật state tại chỗ nhằm đạt hiệu ứng chuyển cảnh mượt mà nhất cho người dùng.
