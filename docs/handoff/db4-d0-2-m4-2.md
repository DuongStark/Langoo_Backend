## CLI

`DIRECT_URL` lấy từ env bảo mật; không dán key/URL chứa password vào chat hoặc report.
Các target dưới đây chỉ là label host:port/database, không phải connection string.
Directory output phải tạo trước; filenames immutable, không ghi đè run cũ.

```bash
# Read-only; default 500, cap 5000. --after dùng nextAfterSenseId của cohort trước.
npx tsx scripts/dictionary/projection-cli.ts export \
  --target 127.0.0.1:5432/langoo --limit 500 \
  --out /opt/langoo/storage/db4/projection/run-001/manifest.json

# Mutate chỉ khi target/live manifest đã review, backup/gates đạt.
npx tsx scripts/dictionary/projection-cli.ts apply \
  --target 127.0.0.1:5432/langoo --allow-data-write \
  --manifest /opt/langoo/storage/db4/projection/run-001/manifest.json \
  --journal /opt/langoo/storage/db4/projection/run-001/apply-journal.json

# Rollback nhận manifest ban đầu, không phải result file; conditional hashes.
npx tsx scripts/dictionary/projection-cli.ts rollback \
  --target 127.0.0.1:5432/langoo --allow-data-write \
  --manifest /opt/langoo/storage/db4/projection/run-001/manifest.json \
  --journal /opt/langoo/storage/db4/projection/run-001/rollback-journal.json

# Candidate inventory + FK counts only. --after/--after-peer lấy hai key từ cohort trước.
npx tsx scripts/dictionary/duplicate-cli.ts \
  --target 127.0.0.1:5432/langoo --limit 500 \
  --out /opt/langoo/storage/db4/duplicates/run-001/inventory.json
```

Nếu journal prepared tồn tại mà không có result, có thể COMMIT đã xảy ra: inspect
before/after state hoặc resume cùng manifest + journal filename mới. Không sửa
before-image, không chạy lại bằng cách đổi digest/hash/target. Một conflict rollback
cả cohort. CLI mutation kiểm function SQL installed hash; migration/policy khác thì dừng.

Raw artifact local ở `uploads/dictionary/db4-d0-20261006/`, gitignored; summary có
file hashes. Export local không dùng để apply VPS bằng cách sửa target. Re-export
