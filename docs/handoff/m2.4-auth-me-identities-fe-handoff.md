# M2.4 — FE Handoff: Trạng thái liên kết Google & Phương thức đăng nhập trong GET /v1/auth/me

Ngày: 2026-10-28. Milestone: `M2.4`.
Backend: Đã nâng cấp API `GET /v1/auth/me` (và các endpoint auth liên quan), 58/58 unit tests pass.

---

## 1. Vấn đề thực tế cần giải quyết trên Frontend

Hiện tại trên trang **Cài đặt / Hồ sơ** (component `GoogleLinkSection`, `data-testid="google-link"`):
- Khối "Liên kết Google" đang được hiển thị **cố định cho mọi tài khoản**, kèm theo ô input bắt buộc người dùng nhập mật khẩu:
  > *"Nhập mật khẩu tài khoản hiện tại để liên kết Google"*
- **Nghịch lý xảy ra:**
  - Đối với người dùng **đăng nhập trực tiếp bằng Google**: Tài khoản của họ trong cơ sở dữ liệu **vốn đã là tài khoản Google** và **không hề có mật khẩu Langoo**.
  - Người dùng không có mật khẩu để nhập, dẫn đến nút liên kết bị disable (mờ đi). Nếu nhập mật khẩu linh tinh thì Backend sẽ trả về lỗi `409 AUTH_OAUTH_LINK_PASSWORD_REQUIRED`.

## 2. Nâng cấp API Backend: Bổ sung trường định danh

Backend đã nâng cấp `UserResponse` trả về từ:
- `GET /v1/auth/me`
- `POST /v1/auth/login`
- `POST /v1/auth/register`
- `POST /v1/auth/oauth/google`

### TypeScript Interface cập nhật

```ts
export interface UserIdentitySummary {
  /** Tên phương thức: 'password' | 'google' */
  provider: string;
  /** Thời điểm liên kết phương thức này */
  created_at: string;
}

export interface UserResponse {
  id: string;
  email: string;
  display_name: string | null;
  avatar_url: string | null;
  status: string;
  created_at: string;
  last_login_at: string | null;

  // --- 3 TRƯỜNG MỚI ĐÃ ĐƯỢC BỔ SUNG ---
  /** Danh sách các phương thức đăng nhập tài khoản đang sở hữu */
  identities: UserIdentitySummary[];
  /** true nếu tài khoản có mật khẩu để đăng nhập bằng email + password */
  has_password: boolean;
  /** true nếu tài khoản đã liên kết với Google */
  has_google: boolean;
}
```

## 4. Hướng dẫn sửa cụ thể cho Frontend (Web & React Native)

Trên component render phần **Liên kết Google** trong trang Cài đặt / Hồ sơ:

```tsx
import { CheckCircle2 } from "lucide-react";

export function GoogleLinkSection({ user }) {
  // 1. Nếu tài khoản ĐÃ liên kết Google: Hiển thị badge trạng thái đã kết nối
  if (user.has_google) {
    return (
      <section className="overflow-hidden rounded-2xl border border-border bg-card p-5" data-testid="google-link">
        <div className="flex items-center justify-between">
          <div className="space-y-1">
            <h2 className="text-sm font-semibold text-foreground">Tài khoản Google</h2>
            <p className="text-xs text-muted-foreground">
              Đã liên kết với email <strong>{user.email}</strong>. Bạn có thể dùng nút Google để đăng nhập bất kỳ lúc nào.
            </p>
          </div>
          <span className="inline-flex items-center gap-1.5 rounded-full bg-emerald-500/10 px-3 py-1 text-xs font-medium text-emerald-600 dark:text-emerald-400">
            <CheckCircle2 className="size-3.5" />
            Đã liên kết
          </span>
        </div>
      </section>
    );
  }

  // 2. Nếu tài khoản CHƯA liên kết Google:
  // - Nếu có mật khẩu: Hiển thị form nhập mật khẩu để liên kết (như hiện tại)
  // - Nếu không có mật khẩu: Hiển thị hướng dẫn thiết lập mật khẩu trước
  return (
    <section className="overflow-hidden rounded-2xl border border-border bg-card" data-testid="google-link">
      <header className="border-b border-border px-5 py-3">
        <h2 className="text-sm font-semibold text-foreground">Liên kết Google</h2>
      </header>
      <div className="space-y-3 px-5 py-4">
        <p className="text-xs text-muted-foreground">
          Liên kết tài khoản Google để đăng nhập nhanh mà không cần nhập mật khẩu.
        </p>

        {user.has_password ? (
          <>
            <div className="space-y-2 sm:max-w-sm">
              <label htmlFor="link-google-password" className="text-xs font-medium">
                Mật khẩu hiện tại
              </label>
              <input
                id="link-google-password"
                type="password"
                placeholder="Nhập mật khẩu tài khoản"
                value={password}
                onChange={(e) => setPassword(e.target.value)}
              />
            </div>
            <div className={password ? "" : "pointer-events-none opacity-50"}>
              {/* Nút Continue with Google */}
            </div>
          </>
        ) : (
          <p className="text-xs text-amber-600">
            Vui lòng thiết lập mật khẩu tài khoản trước khi liên kết thêm tài khoản phụ.
          </p>
        )}
      </div>
    </section>
  );
}
```

### Tóm tắt việc cần làm của FE:
1. Đọc cờ `user.has_google` từ `user` object.
2. Nếu `user.has_google === true`: Thay thế ô nhập mật khẩu bằng nhãn **"Đã liên kết"** có icon tích xanh ✅.
3. Người dùng đăng nhập bằng Google sẽ không bao giờ bị hỏi mật khẩu nữa!
