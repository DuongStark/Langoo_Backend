## Nguồn và kết quả

- [BCCWJ SUW v1.0](https://doi.org/10.15084/00003218), ZIP chính thức từ NINJAL.
- 185.136 corpus rows; 218.794 JMdict lexemes khảo sát. Ghép 66.041 lexemes từ
  71.325 corpus rows; 7.247 rows mơ hồ, 106.564 unmatched. Không gán rank cho hai
  nhóm này. 842/1.000 mục corpus đầu được ghép an toàn; đây là coverage, không phải
  độ chính xác semantic hay tỷ lệ “đủ 99% giao tiếp”.
- Mapping giữ biến thể hợp lệ theo restriction của reading; kana/katakana NFKC,
  coarse POS rõ ràng. Không fuzzy match kanji hoặc truyền tần suất cho mọi từ đồng âm.
  Nhiều corpus sublemma cùng lexeme lấy row có rank tốt nhất, không cộng count dễ trùng.
- BCCWJ là corpus viết cân bằng; không suy ra nghĩa nào phổ biến nhất khi nói chuyện.
  Chính sách nghĩa dùng metadata JMdict và 10 lựa chọn GPT cho 4 entry (猫, 付ける,
  掛ける, 結構). Không tuyên bố đã đo tần suất từng nghĩa hoặc đã review hết 66k mục.

## Cách chạy lại trên VPS

Storage riêng: `/opt/langoo/storage/dictionary-priority/ja-bccwj-20261007`.
Raw ZIP, JMdict snapshot, artifact và audit không nằm trong Git. Khóa SSH `langoo-vps`
đã cấu hình; mọi command dưới đây chạy trên VPS, tại `/opt/langoo/app`.

```bash
node scripts/dictionary/ja-priority-cli.mjs export \
  --target langoo-vps --out /opt/langoo/storage/dictionary-priority/ja-bccwj-20261007/jmdict-snapshot.json
python3 scripts/dictionary/ja-bccwj-prepare.py \
  --snapshot /opt/langoo/storage/dictionary-priority/ja-bccwj-20261007/jmdict-snapshot.json \
  --zip /opt/langoo/storage/dictionary-priority/ja-bccwj-20261007/langoo-bccwj-suw.zip \
  --out /opt/langoo/storage/dictionary-priority/ja-bccwj-20261007/ja-priority.json
# Lấy SHA từ output prepare hoặc sha256sum. Thay SHA256 bên dưới bằng hash thật.
node scripts/dictionary/ja-priority-cli.mjs check --target langoo-vps \
  --file /opt/langoo/storage/dictionary-priority/ja-bccwj-20261007/ja-priority.json --sha256 SHA256
node scripts/dictionary/ja-priority-cli.mjs apply --target langoo-vps \
  --file /opt/langoo/storage/dictionary-priority/ja-bccwj-20261007/ja-priority.json --sha256 SHA256 --apply
```

Apply mặc định dry-run nếu thiếu `--apply`. Bind target label + database + source
version, SHA artifact, external semantic key + input hash; lock/transaction cho run,
validate toàn bộ rồi mới flip active. Hash gồm lexical attributes, source version,
EN sense context; không gồm VI machine gloss hoặc DB4 concept mapping. Phục vụ có
hash guard để tự fallback nếu lexical/sense source drift. Cùng artifact import lại
idempotent; artifact đã inactive không tự bật lại. Artifact rỗng bị từ chối.

Nếu đổi snapshot/source, export và prepare lại; không sửa ID hoặc sửa hash để né gate.
Lựa chọn nghĩa trong `scripts/dictionary/ja-sense-preferences.json` có lemma/reading,
sense_no và EN substring làm guard. Muốn mở rộng cần đọc đầy đủ sense context trước.

## Kiểm thử và rollback

```bash
python3 scripts/dictionary/ja-bccwj-prepare.test.py
node --test scripts/dictionary/ja-priority-cli.test.mjs
# Chỉ DB tên kết thúc _test; không reset production.
node scripts/dictionary/ja-priority.integration.mjs \
  --test-db langoo_m45_test --env-file /opt/langoo/app/.env \
  --artifact /tmp/test-artifact.json --build dist
# Tắt corpus/sense run, giữ metadata fallback trong code:
node scripts/dictionary/ja-priority-cli.mjs deactivate --target langoo-vps \
  --run RUN_UUID --apply
```

Production run UUID / backup path lưu trong report. Full rollback cần restore dist
và các source file từ backup trước deploy, rồi restart **langoo-api** bằng user
langoo với `PM2_HOME=/opt/langoo/.pm2`. Không xóa lexical/sense IDs hay bảng dữ liệu học.
Không chạy build trực tiếp cùng lúc agent khác; fingerprint file trước overlay.
