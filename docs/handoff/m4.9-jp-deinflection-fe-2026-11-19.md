## 1. Trả lời 3 câu hỏi §8 của FE

1. **DB có lưu POS kiểu "suru verb" không?**
   - `core.lexeme.pos` lưu 15 giá trị chuẩn (`noun`, `verb`, `adjective`, `adverb`…), ví dụ trên DB production: `応募` = `noun`, `親切`/`細い` = `adjective`, `ほっと` = `adverb`.
   - BE dùng `expectedPos` của từng quy tắc chia thể làm **ưu tiên xếp hạng mềm** (soft boost, không loại cứng) đúng như Nguyên tắc 4 FE đề xuất.
2. **Tên trường phản hồi thống nhất:**
   - Chốt dùng **`deinflected_from: string | null`** ở cả:
     - `GET /v1/dictionary/search` → `data[].deinflected_from`
     - `GET /v1/dictionary/suggestions` → `data[].deinflected_from`
     - `POST /v1/collections/import` & `POST /v1/collections/:id/items/import` → `added[].deinflected_from`
   - Giá trị: **`null`** khi khớp trực tiếp; **chuỗi mặt chữ gốc người dùng gửi/gõ** khi khớp qua deinflection (hoặc cứu chữ cụt theo reading ở Import).
   - Hoàn toàn tương thích ngược với FE hiện tại.
3. **Search có làm cùng đợt với Import không?**
   - **Đã làm cùng đợt cho cả 3 nơi:** `search`, `suggestions`, và `M5.3 import`. Sau khi BE deploy production, FE có thể gỡ hoàn toàn `useDeinflectionSearch` phía client (giảm từ 5–7 request xuống 1 request duy nhất!).

## 2. Những gì BE đã triển khai

- **Module dùng chung** `src/common/japanese/jp-deinflect.ts` (port từ `jp-deinflect.ts` của FE + mở rộng):
  - Đủ bảng **A** (`する` / `します` / `しました` / `される`…), **B ★ mới** (bỏ `な`, đổi `く → い`, `かった`/`くない`/`くて`/`ければ`), **C** (thể `て`/`た`), **D** (`ます`/`ない`/`ている`/bị động/sai khiến/điều kiện/ý chí/`です`/`だった`), **E** (bất quy tắc `する`/`来る`).
  - Có cả **§4.3** (cụm câu nói ưu tiên thấp: `してくれ`, `してください`, `してくれる`, `てくれ`, `てください` → `勘弁してくれ` khớp `勘弁`).
  - Riêng **M5.3 Import** có thêm **§4.4** (cứu file cụt chữ cuối khi có `reading` kana duy nhất: `引っ越` + `ひっこし` → `引っ越し`; giữ `恥ずかし` với romaji `Hazukashi` là `not_found`).
  - Ưu tiên **exact script** (`ほっとする` chọn `ほっと` thay vì `ホット`), và **luôn khớp chính xác trước** (`みんな`, `板`, `きれい`, `する` không bị cắt đuôi).
- **Kiểm chứng thực tế trên 35 từ `not_found` của file Mazii 1.938 từ (read-only trên DB production):**
  - Gỡ bằng deinflection: **32/35 từ** (gồm cả `勘弁してくれ`)
  - Gỡ bằng §4.4 reading duy nhất: **1/35 từ** (`引っ越` → `引っ越し`)
  - Còn lại `not_found`: **2/35 từ** (`恥ずかし` romaji và `何位`) — đúng như kỳ vọng trong bảng §7.3 của FE!

## 3. Hợp đồng API (Contract mới)

### 3.1. `GET /v1/dictionary/search` & `GET /v1/dictionary/suggestions`

Mỗi phần tử trong `data[]` (`SearchHitDto`) thêm trường `deinflected_from`:

```json
{
  "data": [
    {
      "lexeme_id": "119021",
      "language_id": 2,
      "lang_code": "ja",
      "lemma": "応募",
      "surface": "応募",
      "reading": "おうぼ",
      "pos": "noun",
      "frequency_rank": 4657,
      "frequency_source": "bccwj-suw",
      "homograph_no": 1,
      "surface_kind": "lemma",
      "is_exact": true,
      "deinflected_from": "応募する",
      "preview": { "sense_id": "...", "gloss_vi": "..." }
    }
  ],
  "next_cursor": null
}
```

- **Khi nào `deinflected_from` khác `null`:**
  - Chỉ ở trang đầu (`cursor === null`), khi ngôn ngữ cho phép tiếng Nhật (`lang` là `ja` hoặc không truyền, và hồ sơ có tiếng Nhật), và truy vấn **chưa có hit `is_exact = true`**.
  - Các hit khớp qua deinflection được đẩy lên **đầu mảng `data`** (có sẵn `preview` như hit bình thường).
  - Các hit khớp trực tiếp luôn có `deinflected_from: null`.

### 3.2. `POST /v1/collections/import` & `POST /v1/collections/:id/items/import`

Mỗi phần tử trong `added[]` (`ImportAddedItemDto`) thêm `deinflected_from`:

```json
{
  "index": 0,
  "word": "応募する",
  "item_id": "01a1...",
  "sense_id": "...",
  "lemma": "応募",
  "reading": "おうぼ",
  "pos": "noun",
  "meaning_vi": "...",
  "pos_matched": true,
  "deinflected_from": "応募する"
}
```

## 4. Việc FE cần làm (sau khi BE deploy production)

1. **Cập nhật TypeScript types (`src/types/api.ts`):**
   - `SearchHitDto`: thêm `deinflected_from?: string | null`
   - `ImportAddedItemDto`: thêm `deinflected_from?: string | null`
2. **Đọc `hit.deinflected_from` trực tiếp từ BE ở 3 chỗ tra từ:**
   - Kết quả tra từ (`SearchResultsPanel.tsx` / `SearchResultItem.tsx`)
   - Gợi ý khi gõ (`DictionarySearchBar.tsx`)
   - Tooltip bôi đen (`LookupTooltip.tsx`)
   - Nếu `hit.deinflected_from` khác `null` → hiện chip **"thể chia"** và dòng **"từ “{hit.deinflected_from}”"** giống UI hiện tại.
3. **Xóa logic deinflection gọi nhiều request phía client:**
   - Gỡ `useDeinflectionSearch` ở 3 màn trên để chỉ gọi **1 request** `GET /v1/dictionary/search` hoặc `/suggestions`.
   - Có thể xóa `src/lib/jp-deinflect.ts` và unit test tương ứng khi không còn nơi nào khác ở FE import (kiểm grep trước khi xóa).
4. **Màn tổng kết Import List (`ImportListDialog.tsx` — tùy chọn nhẹ):**
   - Trong danh sách từ đã thêm (hoặc dòng tóm tắt), nếu có item `deinflected_from !== null`, có thể hiện nhãn nhỏ *"khớp dạng gốc: `word` → `lemma`"* (vd `勘弁してくれ → 勘弁`).
