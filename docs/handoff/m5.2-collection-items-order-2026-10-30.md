# M5.2 — FE: thứ tự item collection và cursor

Ngày 2026-10-30. Code local đã thêm `order=desc`; chưa commit/push/deploy VPS.
Endpoint: `GET /v1/collections/:collectionId/items` (Bearer như cũ).

```http
GET /v1/collections/<id>/items?order=desc&limit=100
GET /v1/collections/<id>/items?order=desc&limit=100&cursor=<next_cursor>
```

- `order` chỉ nhận `asc`/`desc`, mặc định asc. Desc là `(position DESC,id DESC)`,
  asc là `(position ASC,id ASC)`. Server lọc/sắp xếp trước LIMIT; response giữ `{data,next_cursor}`.
- Bản ghi thêm sau thường có position lớn hơn. Khi người dùng đã sửa position,
  đây là thứ tự vị trí hiện tại, không phải sort theo created_at.
- Giữ cùng order/filter/collection khi tải trang sau; dùng URLSearchParams để gửi cursor nguyên vẹn.
  Khi đổi order, reset items/cursor và gọi trang đầu. Không đảo riêng mảng của một trang để giả sort.
- Desc cursor có hướng, dùng với asc/bỏ order trả400 VALIDATION_FAILED. Cursor asc trước thayđổi
  vẫn tương thích khi tiếp tục asc. Không decode/chỉnh cursor ở FE.
- Invalid order (DESC/newest/rỗng/array), limit>100, cursor khác chiều:400 VALIDATION_FAILED.
- Các filter language_id/status, profile visibility và ownership vẫn được áp như trước.
