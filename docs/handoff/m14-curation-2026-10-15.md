# Handoff M14 — Admin curation (sửa gloss + nối nghĩa) · 2026-10-15

## Chính sách chủ dự án (chốt 15/10)

- Nội dung máy (gloss VI, mapping LLM) **mặc định OK** — không duyệt trước.
  Sai → user báo (`gloss_report`) → **admin sửa data**: sửa nghĩa, sửa/xoá/thêm nối nghĩa.
- Cổng serve đã mở sẵn cho nội dung máy: 5.546 concept `draft→curated` (reviewed_by NULL),
  `serve.sense_pair` = 482.382 cặp (34.725 cặp có nhánh jmdict máy) — FE "map sang tiếng Anh" đã có dữ liệu.
- Mọi thao tác ghi `core` đều **audit** (`app.admin_audit_log`); mapping/concept đổi →
  refresh `serve.sense_pair` **chạy nền** (~vài giây, không chặn request).

## API admin mới (Bearer admin — AdminGuard như mọi `/v1/admin/*`)

| Endpoint | Mô tả |
| --- | --- |
| `GET /v1/admin/curation/senses?q=&lang=ja&limit=` | tìm sense (lemma/kana/romaji hoặc `external_id`) |
| `GET /v1/admin/curation/senses/:id` | chi tiết: gloss VI/EN (id, is_machine, reviewed…), nối nghĩa, 10 report gần nhất |
| `GET /v1/admin/curation/glosses/:id` | tra gloss theo id (từ `gloss_report.target_id`) + sense chứa nó |
| `GET /v1/admin/curation/concepts?q=&limit=` | tìm concept khi cần thêm nối nghĩa đúng |
| `PATCH /v1/admin/curation/glosses/:id` | `{text?, reviewed?, quality?}` |
| `POST /v1/admin/curation/senses/:id/glosses` | `{text}` — thêm gloss VI |
| `DELETE /v1/admin/curation/glosses/:id` | xoá gloss |
| `POST /v1/admin/curation/senses/:id/mappings` | `{concept_id, relation?}` |
| `DELETE /v1/admin/curation/senses/:id/mappings/:conceptId` | xoá nối nghĩa sai |
| `PATCH /v1/admin/curation/concepts/:id` | `{status: draft｜review｜curated｜rejected}` |
| `POST /v1/admin/curation/serve/refresh` | refresh matview thủ công (bình thường tự chạy nền) |

Chi tiết request/response + mã lỗi: `docs/api/admin.md` §M14.

## Luồng FE/Admin UI gợi ý

1. Hàng chờ: `GET /v1/admin/gloss-reports?status=open` (đã có từ M13).
2. Mở báo lỗi: `target_kind='sense_gloss'` → `GET /v1/admin/curation/glosses/{target_id}`
   → có sense cha → `GET /v1/admin/curation/senses/{sense_id}` để xử lý toàn cảnh
   (gloss VI/EN + nối nghĩa + các report khác).
3. Sửa nghĩa: `PATCH curation/glosses/:id` — sửa text (tự bỏ cờ máy dịch),
   `reviewed=true` để đánh dấu admin đã kiểm; thêm nghĩa thiếu bằng `POST …/glosses`.
4. Sửa nối nghĩa: `DELETE …/mappings/:conceptId` cho nối sai;
   tìm concept đúng bằng `GET curation/concepts?q=` → `POST …/mappings`.
5. Đóng báo lỗi: `PATCH /v1/admin/gloss-reports/:id {status: fixed|rejected}` (đã có).
6. Audit xem tại `GET /v1/admin/audit-log` (action `curation.*`).

## Lưu ý kỹ thuật

- `reviewed_by = NULL` trên concept = "máy mặc định duyệt"; có giá trị = admin đã kiểm.
- Gloss sửa tay tự đặt `is_machine=false` + `source_id` nguồn `admin-curation`.
- Refresh matview single-flight **theo process** (API 1 instance — ổn); nếu scale
  nhiều instance cần thêm mutex DB (chưa làm, ghi chú).
- Nguồn `admin-curation` được seed trong migration `042_m14_curation.sql` (kèm cột
  `core.sense_concept.reviewed_by/reviewed_at`).
